# 계양중학교 소개 — 의견 작성 흐름

## 서비스 설명
계양중학교를 간단히 소개하고 학교생활에 관한 의견을 작성해 보는 수업용 웹페이지이다. 기존 학교 소개, 이미지 표시, 주요 기능, 이용 방법, 페이지 내부 이동을 유지하면서 의견 작성 흐름을 연결했다.

- 주요 사용자: 학교생활에 관심이 있는 학생과 학부모
- 서비스 목적: 학교 정보를 확인하고 학교생활에서 바라는 점을 정리한다.
- 핵심 행동: 의견 입력 → 내용 확인 → 작성 완료
- 완료 조건: 앞뒤 공백을 제외한 의견이 5~100자이고, 확인 화면에서 ‘이 내용으로 완료’를 누른다.
- 완료 표시: ‘의견 작성이 완료되었습니다.’라는 제목, 4 / 4단계 표시, 최종 의견을 보여 준다.

## 사용자 흐름
1. 시작: ‘의견 작성 시작’을 누른다.
2. 입력: 학교생활에 관한 의견을 5~100자로 작성한다.
3. 확인: 작성한 내용을 읽는다. 수정하려면 이전 입력 화면으로 돌아간다.
4. 완료: ‘이 내용으로 완료’를 누르면 완료 상태와 최종 내용을 확인한다.

학교 소개를 읽은 뒤 메뉴의 ‘의견 작성’으로 이동하여 시작할 수 있다. 모든 단계는 같은 페이지에서 진행한다.

## 파일 구성과 구현 방법
- index.html: 학교 소개와 시작·입력·확인·완료의 네 화면
- style.css: 기본 배치, 오류·완료 상태 표현, 모바일 대응
- script.js: 클릭 이벤트, 조건 검사, 단계 전환, 초기화
- README.md: 프로젝트 설명과 확인 기록

기초 JavaScript의 let, if / else if, function, addEventListener를 사용했다. getElementById로 요소를 찾고 hidden으로 단계 화면을 표시하거나 감춘다. textContent로 작성한 의견을 표시한다. 프레임워크나 외부 라이브러리는 사용하지 않는다.

## 입력 유지와 초기화
- 이전 단계로 돌아갈 때 입력창의 value를 지우지 않아 작성한 내용이 유지된다.
- 입력 조건을 검사할 때마다 현재 value를 읽으므로 수정한 내용이 확인 화면에 반영된다.
- 완료 화면은 확인 화면의 최종 문장을 그대로 표시한다.
- 다시 시작하면 입력값, 오류 문구, 확인 내용, 완료 내용이 비워지고 진행 단계가 1로 돌아간다.
- 단계 전환 시 해당 제목으로 초점이 이동하여 새 단계를 확인할 수 있다.

## 실행 방법
1. ZIP 압축을 푼다.
2. index.html, style.css, script.js를 같은 폴더에 둔다.
3. index.html을 브라우저로 연다.
4. 학교 사진을 같은 폴더에 image(4).png라는 이름으로 넣으면 표시된다.

원본 사진은 제공되지 않아 포함하지 않았다. 사진이 없으면 소개 영역에 안내문이 표시된다.

### 직접 확인할 순서
1. 시작 후 빈 값으로 다음 단계 이동을 시도한다.
2. 정상 의견을 입력하고 확인 화면으로 이동한다.
3. ‘의견 수정’으로 돌아가 글을 바꾼 뒤 다시 확인한다.
4. 완료 화면에서 수정한 글과 완료 표시를 확인한다.
5. 다시 시작하여 입력과 오류가 초기화되는지 확인한다.
6. 휴대전화에서도 같은 과정을 확인한다.

## 현재 구현 범위와 다음 확장
현재 버전은 의견의 입력·확인·완료 흐름까지 구현한 프로토타입이다. 학교나 다른 사용자에게 전송하지 않으며, 새로고침하면 상태가 초기화된다.

다음 단계에서는 작성 완료된 의견을 게시판 목록에 추가하고, 게시된 의견에 공감하거나 공감을 취소하는 새 행동으로 확장할 수 있다. 현재 버전에는 게시판·공감 기능을 넣지 않았다.
